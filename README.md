# رَخام | Raw Materials Pro

واجهة عربية باتجاه RTL باسم **القادسية للتجارة · مواد خام البلاستيك** لإدارة المواد والمخزون والموردين والعملاء، مع خادم Python وقاعدة SQLite دائمة. المشروع محلي افتراضيًا ويخزن قاعدة البيانات في `raw_materials.db` بجانب `server.py`.

## التشغيل لأول مرة

1. يتطلب Python 3.10 أو أحدث، ولا يحتاج حزمًا خارجية.
2. من نافذة PowerShell داخل مجلد المشروع أنشئ حساب المدير الأول:

   ```powershell
   python server.py --create-admin
   ```

   أدخل اسم مستخدم، واسمًا ظاهرًا، وكلمة مرور من 12 حرفًا على الأقل. لا توجد حسابات أو بيانات تجريبية جاهزة.

3. شغّل التطبيق:

   ```powershell
   python server.py
   ```

4. افتح `http://127.0.0.1:8000` في المتصفح. أنشئ حسابات الموظفين من «فريق العمل».

يمكن تحديد `HOST` و`PORT` و`RAKHAM_DB` و`RAKHAM_BACKUPS` بمتغيرات البيئة. افتراضيًا يستمع الخادم على `127.0.0.1` فقط؛ لا تعرضه للإنترنت مباشرة. النشر البعيد يحتاج خادم WSGI/ASGI مُدارًا، HTTPS، إعداد ملفات تعريف الارتباط الآمنة، جدارًا ناريًا ومراجعة إعدادات الإنتاج.

## الوظائف الحالية

- تسجيل دخول منفصل، تجزئة كلمات المرور، جلسات محفوظة في قاعدة البيانات، وتحديد محاولات الدخول.
- دور مدير وموظف، وصلاحيات تشغيلية يحددها المدير عند إنشاء الموظف.
- إرجاع سعر البيع للمدير فقط؛ تختبر اختبارات HTTP أن السعر لا يظهر للموظف في واجهات المواد أو الحركات، وأن نقاط التقارير والإدارة مرفوضة.
- مواد وموردون وعملاء ومخزن رئيسي، وحركات توريد وبيع تسجل معها الكمية والمستخدم والتاريخ والتكلفة.
- بحث عن الخامات وفتح بطاقة تفصيلية تعرض بيانات المادة والمورد المرتبط وسجل مصادر التوريد والتكلفة والتاريخ والملاحظات، مع إخفاء سعر البيع عن الموظف في استجابة الخادم.
- معاملات SQLite لمنع الخصم المتزامن فوق الكمية المتاحة، ومفتاح `Idempotency-Key` لمنع تكرار حركة الإرسال.
- سجل تدقيق لمحاولات الدخول والحركات والإضافات، ونسخة احتياطية متسقة من قاعدة البيانات.
- لوحة مدير وتقارير لفترة زمنية، مع تصدير CSV وطباعة المتصفح.

## الحدود الحالية قبل الاستخدام التشغيلي

هذه نسخة محلية أولية وليست ERP مكتملًا أو منشورًا للإنتاج. تستخدم SQLite ومخزنًا رئيسيًا واحدًا؛ لا توجد بعد مستندات فواتير كاملة أو دورة اعتماد قابلة للتهيئة، أو مدفوعات وحسابات دائنة، أو مرتجعات وتسويات، أو تكلفة شحن وجمارك موزعة، أو تحرير/تعطيل حسابات بعد إنشائها، أو استعادة نسخة احتياطية من داخل الواجهة. كذلك لا يوجد نشر PWA أو مزامنة دون اتصال أو نسخ احتياطي مجدول. نفّذ الاستعادة يدويًا بعد إيقاف الخادم وأخذ نسخة من ملفات قاعدة البيانات أولًا. يلزم استكمال هذه الأجزاء ومراجعة أمنية وتشغيل تجريبي قبل اعتماد النظام لإدارة أموال الشركة أو إتاحته عبر شبكة عامة.
